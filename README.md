# Mohammad Yazdani — Personal Website

Personal academic website of **Mohammad Yazdani**, a Process Systems Engineering (PSE) researcher working on modeling and optimization of low-carbon chemical processes.

**Live site:** https://mohammmadyazdani.github.io/

## About

I work in Process Systems Engineering, developing modeling and optimization methods for low-carbon chemical processes, with a focus on CCUS, Power-to-X, and the flexible operation of separation and conversion processes.

The site presents my research interests, education, research experience, publications, teaching, projects, and CV.

## About this repository

A static site (plain HTML, CSS, and JavaScript, no build step), served with GitHub Pages.

```
index.html          # the whole site
CV - Mohammad Yazdani.pdf
og-image.jpg        # social sharing image
favicon.*, icon-*.png, apple-touch-icon.png
robots.txt
```

To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.
